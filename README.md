# Time Series Analysis Tutorial

This repository contains Python scripts for time series analysis and forecasting, covering fundamental concepts and techniques.

## Contents

The tutorial covers:

1. **Basic Time Series Modeling**
   - Time-step features
   - Lag features
   - Linear regression for trend analysis

2. **Advanced Techniques**
   - Seasonality modeling (indicators and Fourier features)
   - Serial dependence analysis
   - Hybrid models (combining linear models with XGBoost)

3. **Practical Applications**
   - Book sales forecasting
   - Tunnel traffic prediction
   - Flu trends analysis
   - Retail sales forecasting

## Datasets

The tutorial uses several datasets:
- `book_sales.csv` - Daily book sales data
- `tunnel.csv` - Daily tunnel traffic data
- `flu-trends.csv` - Weekly flu-related data
- `us-retail-sales.csv` - Monthly retail sales data
- `reserve.csv` - Federal Reserve interest rates

## Key Features

- Feature engineering for time series
- Visualization techniques
- Model evaluation
- Forecasting methods
